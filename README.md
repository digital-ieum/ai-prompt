# AI 프롬프트 체험관

고르기만 하면 AI에게 보낼 문장이 완성되는 시니어 수업용 웹사이트입니다.
완성된 문장을 복사해 제미나이·챗GPT·Flow에 붙여넣어 씁니다.

- 주소: https://digital-ieum.github.io/ai-prompt/
- 만든 사람: 디지털이음 조민영
- 사이트 안에서 AI를 부르지 않고, 입력한 내용을 저장하거나 보내지 않습니다.
- 그림은 모두 AI로 만든 예시이며, 그림 아래 'AI로 생성한 이미지입니다.' 표시를 지우지 않습니다.
- 내용 원본은 관리표(구글 시트)이고, `sync.py`로 `data.js`를 만듭니다.
